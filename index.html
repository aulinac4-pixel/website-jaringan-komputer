01 / TOOLKIT

Alat & Bahan

Siapkan seluruh komponen sebelum mulai merangkai kabel LAN crossover.

01

RJ45

Konektor untuk menghubungkan kabel UTP dengan port Ethernet.

02

Kabel UTP

Kabel jaringan yang memiliki delapan inti kabel kecil.

03

LAN Tester

Digunakan untuk mengecek kontinuitas dan urutan kabel.

04

Tang Crimping

Digunakan untuk mengunci konektor RJ45 pada kabel.

02 / CRIMPING

Merangkai Kabel LAN Crossover

Ikuti setiap langkah secara berurutan agar kabel rapi dan dapat digunakan.

01

Potong & Kupas

Potong kabel UTP sesuai kebutuhan, kemudian kupas bagian luarnya sekitar 2–3 cm.

02

Pisahkan 8 Kabel

Pisahkan delapan kabel kecil dan luruskan masing-masing kabel.

03

Susun T568A

Susun ujung pertama menggunakan standar T568A dan potong rata.

04

Masukkan RJ45

Masukkan seluruh kabel ke RJ45 sampai menyentuh bagian ujung konektor.

05

Crimping

Masukkan RJ45 ke tang crimping lalu tekan sampai konektor terkunci.

06

Ujung Kedua T568B

Ulangi proses untuk ujung kedua dengan susunan T568B.

07

Test Kabel

Gunakan LAN tester dan periksa urutan lampu 1 sampai 8.

08

Jika Gagal

Periksa kembali susunan warna dan lakukan crimping ulang jika diperlukan.

04 / NETWORK

Menghubungkan 2 Laptop

Hubungkan dua laptop menggunakan kabel LAN crossover dan atur alamat IPv4 secara manual.

01

Hubungkan Kabel

Colokkan kedua ujung kabel LAN ke port Ethernet masing-masing laptop.

02

Buka Pengaturan

Control Panel → Network and Sharing Center → Change adapter settings.

03

Atur IPv4

Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4) → Properties.

04

Simpan

Masukkan IP sesuai tabel lalu klik OK.

PengaturanLaptop 1Laptop 2
IP Address192.168.1.1192.168.1.2
Subnet Mask255.255.255.0255.255.255.0
05 / TEST

Cek Keterhubungan

Gunakan Command Prompt untuk menguji koneksi kedua laptop.

01

Buka CMD

Tekan Windows + R, ketik cmd, lalu Enter.

02

Laptop 1 → Laptop 2

ping 192.168.1.2
03

Laptop 2 → Laptop 1

ping 192.168.1.1
04

Hasil

Jika muncul “Reply from”, koneksi berhasil merespons.

06 / FILE SHARING

Sharing File via LAN

01

Pilih Folder

Pilih folder yang ingin dibagikan di Laptop 1.

02

Aktifkan Sharing

Klik kanan → Properties → Sharing → Advanced Sharing → Share this folder → Apply.

03

Akses Laptop 2

Tekan Windows + R lalu masukkan:

\\192.168.1.1
04

Transfer File

Buka folder yang tampil lalu lakukan copy/paste sesuai izin akses.
